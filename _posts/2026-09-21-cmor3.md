Features
* User input files can now override the `source`, `experiment`, and `institution` global-attribute values when those attributes are not required by the controlled vocabulary. ([#988][issue-988]{:target="_blank"}, [#995][pr-995]{:target="_blank"})
* Added CMIP7 `site` dimension examples for Python, Fortran, and C, including their generated NetCDF headers and run-script support. ([#997][issue-997]{:target="_blank"}, [#1000][pr-1000]{:target="_blank"})

Bugfixes
* Corrected the ordering of projected-grid coordinates in the complex-grid example and CRS tests from `[x, y]` to `[y, x]`. ([#996][issue-996]{:target="_blank"}, [#998][pr-998]{:target="_blank"})

Changes
* Updated the CMIP7 tables submodule and associated tests.

Issues / Pull Requests

* [Reverse the order of the projection coordinates of grids from `[x, y]` to `[y, x]` (#998)][pr-998]{:target="_blank"}
* [Additional CMOR example (for "site" data) (#997)][issue-997]{:target="_blank"}
* [Add examples that use the `site` dimension (#1000)][pr-1000]{:target="_blank"}
